PikoPe backend + admin — Hostinger (same DB as pikope.bet369win.com)
=====================================================================

Live API example: https://pikope.bet369win.com
Also used:        https://adminnew.pikope.com  (set APP_URL in .env to your domain)
Landing site:     https://pikope.com → public_html/ (site-pikope.com/)

1) Git clone / pull → upload to:
     public_html/pikope/
     Document root MUST be:
     public_html/pikope/public

2) Copy .env.example → .env (never commit .env). Production pattern:
     DB_HOST=localhost
     DB_NAME=u811189100_pikope   (your hPanel MySQL name)
     DB_USER=u811189100_pikope
     DB_PASS=***
     APP_URL=https://pikope.bet369win.com
     ADMIN_USER=admin
     ADMIN_PASS=***  (change from default)
     APP_DEBUG=0
     APP_TEST_HOOKS=0
     Then: php bin/migrate.php && php bin/doctor.php

3) Existing database: do NOT re-import schema.sql on production.
     migrate.php only adds missing tables/columns — keeps player/wallet data.

4) ZiniPay → Brand website = same host as APP_URL
     Webhook: {APP_URL}/webhooks/zinipay

5) Admin: {APP_URL}/admin
     Landing (pikope.com): /admin/landing — APK, screenshots, BN/EN

6) Cron every 5 min: php .../pikope/bin/cleanup.php
